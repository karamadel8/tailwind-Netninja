# Food Ninja 🍕

A recipe website built with Tailwind CSS while following the Net Ninja Tailwind tutorial.

## Built With

- HTML
- Tailwind CSS v4
- JavaScript
- Heroicons

## What I Learned

- Setting up Tailwind CSS v4
- Custom theme colors and fonts
- Responsive grid layouts
- Flexbox for navigation
- DOM manipulation for mobile menu toggle
- Uploading projects to GitHub
